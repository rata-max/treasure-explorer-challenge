THE NON-NEGOTIABLE RULE절대 규칙

No exit, no score.출구 미도달 시 점수 없음.

Collected treasure counts only when the agent reaches the exit. A safe baseline is valid; stronger planning earns a higher score.수집한 보물은 에이전트가 출구에 도달해야만 점수로 인정됩니다. 안전한 기본 전략은 유효하며, 더 강한 계획은 더 높은 점수를 얻습니다.

01 / OBJECTIVE AND EXECUTION01 / 목표 및 실행

Observe. Plan. Act. Repeat.관측. 계획. 행동. 반복.

Core objective핵심 목표

  • Reach the exit within the energy budget.에너지 예산 내에 출구에 도달하세요.
  • Collect valuable treasure without sacrificing a safe exit.안전한 출구 경로를 희생하지 않고 가치 있는 보물을 수집하세요.
  • Reduce wasted movement and invalid actions.불필요한 이동과 무효 행동을 줄이세요.
  • Generalize across every map in the stage.단계의 모든 맵에 범용적으로 대응하세요.

Turn structure턴 구조

  • The engine calls choose_action(observation) once per turn.엔진은 매 턴 choose_action(observation)을 한 번 호출합니다.
  • The agent returns exactly one supported action.에이전트는 지원되는 행동 하나만 반환합니다.
  • The engine updates position, energy, collection state, and visible information.엔진은 위치, 에너지, 수집 상태, 가시 정보를 업데이트합니다.
  • The next decision uses the updated observation.다음 결정은 업데이트된 관측을 사용합니다.

02 / ACTIONS AND ENERGY02 / 행동 및 에너지

Every decision has a cost.모든 결정에는 비용이 따릅니다.

Supported actions지원 행동

  • MOVE_UP, MOVE_DOWN, MOVE_LEFT, MOVE_RIGHT
  • COLLECT while standing on an uncollected treasure미수집 보물 위에서 COLLECT
  • Cost is charged when entering a cell: normal, start, exit, and treasure 1; mud 4; water 7.셀에 진입할 때 비용이 부과됩니다: 일반·시작·출구·보물 1, 진흙 4, 물 7.
  • COLLECT costs 1. Week 1 maps contain only unit-cost terrain.COLLECT는 에너지 1을 소비합니다. 1주차 맵은 단위 비용 지형만 포함합니다.

Invalid actions무효 행동

  • Moving outside the map, into a wall, or without enough energy맵 밖으로 이동, 벽으로 이동, 에너지 부족 이동
  • Collecting without an available treasure at the current position현재 위치에 수집 가능한 보물이 없을 때 COLLECT
  • Returning an unsupported value or raising an exception지원되지 않는 값 반환 또는 예외 발생
  • An invalid action leaves position and energy unchanged, consumes one turn, and subtracts 5 points after a successful exit.무효 행동은 위치와 에너지를 변경하지 않고 한 턴을 소비하며, 성공적인 출구 이후 5점을 차감합니다.
  • Repeated invalid actions can also reach the map's maximum-turn limit.반복된 무효 행동은 맵의 최대 턴 제한에 도달할 수 있습니다.

03 / TREASURE, EXIT, AND SCORE03 / 보물, 출구, 점수

Optimize the complete expedition.전체 탐험을 최적화하세요.

Treasure and exit보물과 출구

  • Arriving at a treasure does not collect it; use COLLECT.보물에 도착한다고 자동으로 수집되지 않습니다. COLLECT를 사용하세요.
  • Entering the exit immediately ends the run.출구에 진입하면 즉시 실행이 종료됩니다.
  • The exit is a final destination, not an intermediate waypoint.출구는 최종 목적지이며 중간 경유지로 사용할 수 없습니다.
  • Preserve the energy required for a safe exit.안전한 출구에 필요한 에너지를 항상 확보하세요.

Base score기본 점수

  • Exit Bonus + Treasure Value + Remaining Energy - Invalid Penalties출구 보너스 + 보물 가치 + 남은 에너지 - 무효 행동 패널티
  • Default exit bonus: 50.기본 출구 보너스: 50.
  • Default invalid-action penalty: 5 per action.기본 무효 행동 패널티: 행동당 5점.
  • A run that does not reach the exit receives 0.출구에 도달하지 못한 실행은 0점입니다.

04 / INFORMATION CONTRACT04 / 정보 계약

Use only what the agent is allowed to know.에이전트가 알 수 있도록 허용된 정보만 사용하세요.

Observation관측 (Observation)

  • Observation may include turn, position, energy, visible grid, exit, and treasure information.관측에는 턴, 위치, 에너지, 가시 격자, 출구, 보물 정보가 포함될 수 있습니다.
  • ? means unobserved, not safe or normal terrain.?는 미관측을 의미하며 안전하거나 일반적인 지형을 의미하지 않습니다.
  • Information may be remembered within the same run.정보는 같은 실행 내에서 기억할 수 있습니다.
  • Separate runs must start with independent state.별도의 실행은 독립적인 상태에서 시작해야 합니다.

Prohibited access금지된 접근

  • No access to original maps, hidden maps, seeds, or engine internals원본 맵, 숨겨진 맵, 시드, 엔진 내부에 접근 금지
  • No file discovery, networking, subprocesses, or environment probing파일 탐색, 네트워크, 서브프로세스, 환경 탐지 금지
  • No reflection or side channels intended to recover hidden state숨겨진 상태를 복원하기 위한 리플렉션 또는 사이드 채널 금지
  • No information sharing between evaluation runs평가 실행 간 정보 공유 금지

05 / GENERALIZATION AND SUBMISSION05 / 범용화 및 제출

Submit an algorithm, not a route.경로가 아닌 알고리즘을 제출하세요.

One generic agent하나의 범용 에이전트

  • Submit the root-level agent.py included in each released stage ZIP.배포된 단계 ZIP에 포함된 루트 레벨 agent.py를 제출하세요.
  • The evaluator loads that same file independently for every map in the stage.평가기는 단계의 모든 맵에 대해 동일한 파일을 독립적으로 로드합니다.
  • Do not branch on filenames, titles, seeds, dimensions used as fingerprints, or memorized layouts.파일 이름, 제목, 시드, 지문으로 사용되는 크기, 또는 기억된 레이아웃으로 분기하지 마세요.
  • Using observed grid dimensions and contents as ordinary algorithm inputs is allowed.관측된 격자 크기와 내용을 일반적인 알고리즘 입력으로 사용하는 것은 허용됩니다.

Submission boundary제출 범위

  • Modify and submit agent.py only unless a stage page explicitly requests a report.단계 페이지에서 보고서를 명시적으로 요청하지 않는 한 agent.py만 수정하여 제출하세요.
  • Do not modify the engine, maps, runner, tests, or configuration; evaluation uses clean official copies.엔진, 맵, 러너, 테스트, 설정은 수정하지 마세요. 평가는 공식 원본을 사용합니다.
  • Use Python 3.11+ and the standard library only unless a stage explicitly states otherwise.단계에서 명시하지 않는 한 Python 3.11+ 표준 라이브러리만 사용하세요.
  • Week 2 and Week 3 artifacts, exact filenames, and stage-specific limits are announced when those stages unlock.2주차·3주차 산출물, 파일 이름, 단계별 제한은 해당 단계가 공개될 때 발표됩니다.

06 / RUNTIME AND EVALUATION06 / 런타임 및 평가

Strong, safe, and efficient.강력하고, 안전하고, 효율적이게.

Runtime contract런타임 계약

  • The public Week 1 runner has a maximum of 500 turns and no separate per-action timer.공개 1주차 러너는 최대 500 턴이며 별도의 행동별 타이머가 없습니다.
  • Infinite loops or an uncaught exception can terminate or invalidate a run.무한 루프나 처리되지 않은 예외는 실행을 종료하거나 무효화할 수 있습니다.
  • Any later per-action, total-runtime, or memory limit must be stated on that stage page before release.이후 행동별·전체 런타임·메모리 제한은 해당 단계 페이지에서 배포 전에 명시됩니다.
  • Viewer delay is display time and is not part of algorithm performance.뷰어 지연은 표시 시간이며 알고리즘 성능에 포함되지 않습니다.

Evaluation signals평가 신호

  • Per-map score: 50 + collected treasure + remaining energy - 5 × invalid actions, only after reaching the exit맵별 점수: 50 + 수집한 보물 + 남은 에너지 - 5 × 무효 행동 (출구 도달 후에만)
  • Exit rate and invalid-action count across the stage map set단계 맵 세트 전체의 출구 도달률 및 무효 행동 횟수
  • Runtime, code quality, and required design explanation런타임, 코드 품질, 필수 설계 설명
  • Week 3 Thursday may add unseen hidden-seed maps under its published evaluation contract.3주차 목요일은 공개된 평가 계약에 따라 미공개 숨겨진 시드 맵이 추가될 수 있습니다.
